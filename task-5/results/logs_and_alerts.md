### Логи
Для работы с логами предлагается классическое решение на стеке ELK, где с помощью сервиса filebeats мониторятся соотв. папки с логами docker контейнеров. Фактически, это стандарт и выбирать тут особо не приходится. Каждый докер контейнер должен писать логи в соотв. json формате для единообразия. Возможно, этот момент придется отдельно донастроить.

Выбрал наиболее простой вариант из коробки -- grafana. Есть адекватный ui, в любом случае тоже своего рода стандарт, поэтому  первое вермя можно не ставить какие-то дополнительные решения, а использовать то что есть.
